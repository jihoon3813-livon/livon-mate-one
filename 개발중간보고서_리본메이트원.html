Ⅰ. 경영 요약 (Executive Summary)

본 프로젝트는 (주)리본케어(Livon Care)의 기존 엑셀 수기 관리 체계를 완전히 탈피하고, [간병 신청 접수 ➔ 간병인 배정 ➔ 모바일 음성 일지(STT) ➔ 보험청구 및 간병비 정산]에 이르는 전 과정을 단일 웹 플랫폼으로 통합하는 전사 통합 ERP 시스템(Livon Mate One) 구축 사업입니다.

현재 핵심 업무 프로세스 및 엑셀 실데이터 연동이 완료되었으며, 업무 처리 소요 시간 70% 이상 단축 및 보험 청구 누락·미수금 발생 원천 차단을 목표로 순항하고 있습니다.

Ⅲ. 주요 개발 성과 및 핵심 기능

1. 원스톱 통합 간병 운영 허브 (Care Hub)

  • 360° 고객 통합 뷰: 환자 정보, 입원 병원, 배정 간병사, 손해사정사(손사), 수납/미수 현황을 단일 카드로 종합 관리
  • 상담원 특화 UI/UX: 글자 크기 4단계 조절 (90%~130% 확대 지원), 상세 카드 열람 시 주변 딤(Dim) 집중 모드, 6종 맞춤 테마
  • CS 상태 태깅: 긴급, 강성, 중요, 민원, 일반 등 상황별 직관적 컬러 태깅 지원

2. AWS 클라우드 연동 음성 간병일지 (Care Logs)

  • 간병사가 모바일에서 녹음한 음성을 사내 AWS S3(livonmate-audio-raw)로 안전하게 전송
  • AWS Transcribe(STT) 연동으로 음성을 텍스트 일지로 자동 변환하여 보험 청구 서류로 즉시 연계

3. 미수금 제로(ZERO) 보험청구 & 간병비 지급 관리

  • 현대해상, 삼성화재 등 주요 손해보험사별 복잡한 정산 공식 자동 계산
  • 환자 자부담금, 보험사 청구액, 간병비 실지급액, 세금(원천징수)/수수료 자동 산출
  • 상단 헤더에 '미확인 청구건 뱃지'를 상시 노출하여 미수금 누락 원천 봉쇄

4. 카카오 로컬 API 기반 전국 병원 지능형 검색

  • 카카오 공식 로컬 API 연동을 통해 병원명 입력 시 정확한 명칭, 도로명 주소, 진료과목, 대표번호 자동 완성
  • 수기 주소 오입력으로 인한 행정 착오 100% 방지

5. 보험사 특화 서식 및 삼성화재 일일 사전명단

  • 삼성화재 전용 엑셀 추출: 매일 작성하던 삼성화재 제출용 명단을 원클릭으로 완벽 생성
  • 4종 필수 서식 센터: 간병사실확인서, 간병비 영수증, 표준 계약서 등 인쇄 및 모바일 팩스 연동 완료

6. 보안 및 개인정보보호 준수

  • 원클릭 개인정보 마스킹: 화면 노출 시 주민등록번호 및 연락처 즉시 암호화 표기 (개인정보보호법 완벽 준수)
  • 역할 기반 권한 분리 (RBAC): 최고관리자(SUPER_ADMIN), 일반 관리자, 상담원 접근 통제

Ⅳ. 비즈니스 기대 효과 (ROI)

[정량적 성과]
